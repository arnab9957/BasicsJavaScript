# JavaScript Basics Learning Project

This repository is a small JavaScript practice project covering foundational browser scripting, DOM manipulation, async programming, objects, promises, and OOP concepts.

## Project Structure

- `index.html` – basic DOM examples and JavaScript usage
- `APIRequest/` – example of fetching GitHub user data using `XMLHttpRequest`
- `AsyncProject/` – JavaScript async and timer examples
- `autoChangeColour/` – color-changing interaction examples
- `closures/` – closure-related example
- `OPP/` – object-oriented programming examples, classes, inheritance, prototypes
- `promise/` – Promise and async/await learning examples

## Topics Covered

- JavaScript basics
- DOM manipulation
- Events and browser interaction
- API requests
- Timers and async flow
- Closures
- OOP concepts
- Classes and prototypes
- Promises and async/await

## How to Run

1. Open the project folder in any code editor.
2. Open any HTML file in a browser.
3. If you want a smoother workflow, use a VS Code extension like Live Server.

Example:

- Open `index.html` in the browser
- Open `APIRequest/index.html` for the API request demo
- Open `closures/closures.html` for the closure example

## Notes

This project is designed for learning and experimentation. Most files are simple script examples and are not meant to be a production app.

## Recommended Learning Order

1. `index.html`
